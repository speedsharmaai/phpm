Every night the sweep installs each project in the corpus twice, once with Composer and once with phpm, at the same path and with the same flags, and compares vendor/ (plus the bin dir, web/, public/, config/ and bootstrap/) byte for byte, file modes included. pure is --no-scripts --no-plugins --ignore-platform-reqs: phpm's own install. default is --ignore-platform-reqs: what a user gets, including steps phpm hands to Composer. Projects Composer itself cannot install are listed but left out of the ratio. Two differences that come from Composer itself are left out and noted on the row: the random APCu prefix in autoload_real.php, and autoloader files whose order on a first install follows the order packages finished installing (left out only when composer dump-autoload then gives phpm's bytes).
