# Phase 06 tasks

Engineering can start now, in parallel with Phase 05 closing out. **Nothing
in the "Public steps" section happens without the owner saying go**, each
time, no matter how ready the engineering is.

## Release engineering (can start now)

- [ ] `cargo dist init`, SHA-pin and zizmor-clean the generated workflow, add `actions/attest` for provenance. Targets: x86_64/aarch64 macOS, x86_64/aarch64 Linux (musl), x86_64 Windows.
- [ ] `curl | sh` and PowerShell installers (cargo-dist generates these; verify the generated scripts).
- [ ] Homebrew tap: `speedsharmaai/homebrew-phpm` repo, formula generated by cargo-dist, verified with a local `brew install --build-from-source` against a draft tag.
- [ ] npm wrapper package (`@speedsharmaai/phpm` or `phpm`, check availability) that downloads the right release binary on `postinstall`, matching the uv/ruff pattern.
- [ ] Packagist wrapper package (`speedsharma/phpm` or similar) so `setup-php` (`tools: phpm`) works day one even before an upstream PR lands.
- [ ] `speedsharmaai/setup-phpm` GitHub Action: installs phpm, caches the store between runs.
- [ ] Docker image + a documented multi-stage pattern for PHP-free build stages.
- [ ] A worktree recipe doc: many agent worktrees, one store, near-zero disk — the agent-workflow pitch made concrete.
- [ ] Crate/registry names reserved early if not already (checked once in ADR 0001 research; re-verify nothing was taken since).
