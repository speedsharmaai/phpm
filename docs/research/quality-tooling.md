# Quality tooling for a Rust CLI, 2026

Researched 2026-10-01. Versions from the crates.io and GitHub release APIs
that day. [U] = not fully verified.

## Three things that shape the plan

1. **A free private repo cannot use several GitHub features.** CodeQL code
   scanning, artifact attestations, Scorecard and rulesets all need the repo
   public or a paid plan [U on whether Pro unlocks rulesets]. phpm is public
   from day one (decision 0009), so all of them are on in Phase 00.
2. **Byte-exact output shapes the tooling.** Whitespace fixers excluded from
   fixtures and snapshots; `.gitattributes` `-text` on them; clippy's
   `iter_over_hash_type` on (Ruff uses it) so HashMap order never leaks.
3. **Upstream health.** taplo is unmaintained; the ecosystem moved to tombi.
   cargo-dist (0.32.0, 2026-05-21) is slowing; uv's release.yml was "originally
   generated by cargo-dist" and is "maintained manually" now. divan has not
   released since 2025-04.

Members: `[lints] workspace = true`, `publish = false` unless published.

Note: `unsafe_code = "forbid"` cannot be overridden by `#[allow]`. The clonefile
FFI module needs `deny` at workspace level plus a local `allow` with a reason,
or the FFI lives in a small crate that sets its own level. Decide in Phase 01.

### CI outline
`permissions: {}` at top, per-job grants; every action pinned by SHA with a
version comment; `persist-credentials: false`; concurrency cancel-in-progress.

1. fmt: `cargo fmt --all --check`, `tombi format --check`
2. clippy (ubuntu, windows): `--workspace --all-targets --all-features --locked -- -D warnings`
3. docs: `RUSTDOCFLAGS=-D warnings cargo doc --workspace --no-deps`
4. test (ubuntu, macos, windows): `cargo nextest run --workspace --locked`, `cargo test --doc`, `INSTA_UPDATE=no`
5. coverage (ubuntu): `cargo llvm-cov nextest --lcov --output-path lcov.info --fail-under-lines 80`
6. msrv: `cargo hack check --rust-version --workspace --locked`
7. deny, shear, typos, zizmor, `prek run --all-files --hook-stage manual`
8. ci-ok: `re-actions/alls-green`, the single required check

Separate: `pr-title.yml` (`on: pull_request`, never `pull_request_target`),
`sonar.yml`, `release-plz.yml`, `release.yml` (dist), and `codeql.yml` +
`codeql.yml`, `scorecard.yml`.

### Release chain
release-plz opens a release PR (version bump, git-cliff changelog) → merge →
release-plz tags and creates the GitHub release → the dist workflow builds
binaries on that tag and runs `actions/attest` v4.2.2. The tag is the only
handoff between them.

## Sonar

Rust is first-class in SonarQube Cloud (April 2025 in SonarQube; cloud blog
2026-09-22): 122 curated clippy rules, cognitive and cyclomatic complexity,
duplication, quality gates. Wiring: `sonar.rust.lcov.reportPaths=lcov.info`,
`sonar.rust.clippyReport.reportPaths=clippy.json` from
`cargo clippy --message-format=json`, via `SonarSource/sonarqube-scan-action`
v8.3.0. CI-based analysis only for Rust [U].

Pricing: free for public projects; the free plan also covers private projects
up to 50k LOC; Team from $34/month for 100k LOC.

Research verdict: mostly duplicates clippy for a solo project. Owner asked for
it, and on a public repo it is free, so it is in as a blocking gate
(decisions 0008, 0009). Its real
value is the complexity and duplication view and a credible badge at launch.

Alternatives: Codecov (free for open source; private: 250 uploads/month for
one user) for PR coverage comments; Qlty (free for OSS; Rust coverage [U]).

## What the projects we admire do

- **uv**: SHA-pinned actions; clippy ubuntu+windows `-D warnings`;
  cargo-deny; `cargo shear --deny-warnings`; typos; shellcheck; zizmor;
  Renovate with MSRV bumps delayed 85 days; hand-maintained release.yml with
  attestations and a 2FA-gated release environment.
- **Ruff**: edition 2024, `rust-version = 1.96`; pedantic warn plus
  `unsafe_code`, `unreachable_pub`, `print_stdout`, `print_stderr`,
  `dbg_macro`, `iter_over_hash_type`, `redundant_clone`; nextest + insta; MSRV
  job; `cargo publish --dry-run`; rustdoc `-D warnings`; cargo-deny;
  cargo-shear; CodSpeed; fuzzing; prek; typos, zizmor, actionlint,
  markdownlint, mdformat in pre-commit.
- **ripgrep**: minimal; big cross-target matrix; rustfmt; rustdoc; no clippy
  job; actions not SHA-pinned.
- **mago** (closest peer): MIT OR Apache-2.0; edition 2024; pedantic, nursery,
  perf and restriction at deny with ~100 allows; clippy + fmt on three OSes ×
  stable/nightly; typos; just; hand-written release on tags, 13 targets,
  attest-build-provenance, ghcr.
- Common to all: pinned toolchain, fmt and clippy as hard gates, typos, dual
  licence. The security-minded (Astral) add SHA pins, zizmor, deny, shear.
