# 0001: The working name is phpm

Status: accepted (provisional until the trademark search)
Date: 2026-10-01

## Context

The Rust-Composer field already used the obvious names and a whole musical
theme: libretto, concerto, vivace, vivacity, riff, lectern, tusk, presto.
Picking another one of those would make phpm look like a copy of a copy.

About 40 candidates were checked on 2026-10-01 against crates.io, npm,
Homebrew formulae and casks, Packagist, GitHub repository search, local
command collisions, and DNS for `.dev`, `.sh` and `get<name>.com`.

Short list:

| Name | crates.io | npm | Homebrew | GitHub | Domains | Risk |
|---|---|---|---|---|---|---|
| phpm | free | free | free | no exact repo | .dev, .sh, getphpm.com unregistered | reads close to phpmd and phpMyAdmin at a glance |
| vendo | free | free | free | runvendo/vendo, 627 stars (AI product) | vendo.sh unregistered | name shared with a live product |
| phap | free | free | free | small unrelated repos | unregistered | obscure |

Taken or conflicted: vend, vendr (a SaaS company), pkgr, pim (pimcore), phpx
(swoole), pax (POSIX binary), quill and cask (Homebrew), tusk, presto,
vivace and lectern (both already Rust Composer clones).

## Decision

**phpm.** It says what it is, reads like pnpm, which is the closest mental
model (a global store linked into each project), and is free everywhere that
matters.

## Consequences

- Trademark search (USPTO, EUIPO, IP India class 9/42) before any public
  artifact.
- Reserve the crate and the npm name early with placeholder publishes on the
  brand account; the field is moving weekly.
- If the search fails, vendo is the fallback and this record is superseded.
